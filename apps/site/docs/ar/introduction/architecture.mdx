قاعدة واحدة تحكم كل ما يلي: **التنفيذ محلي، والسجل مركزي.**

## الخريطة

الرسم أدناه بالإنجليزية عمدًا: خلط العربية داخل كتلة رسم بالمحارف يكسر محاذاة الأعمدة، والمصطلحات
فيه معرّفات تقنية على أي حال. والشرح العربي يليه.

```text
   EMPLOYEE MACHINE                                CLOUDFLARE EDGE (org account)
 ┌───────────────────────────────┐              ┌──────────────────────────────────────┐
 │  Desktop app (Electron)       │              │  wfc-api — one Worker, api.wolffi.sh │
 │  ┌─────────────────────────┐  │              │                                      │
 │  │ 15-region brain         │  │  ──https──▶  │  /auth      sessions, pairing        │
 │  │ capabilities + tools    │  │              │  /ai/v1/…   model lane               │
 │  │ shell · files · browser │  │              │  /v1/search search lane              │
 │  └─────────────────────────┘  │              │  /v1/sync…  conversations, files     │
 │  ~/.wfc  ← cache              │              │  /v1/bridge desktop ↔ phone          │
 └───────┬───────────────────────┘              │  /admin     governance               │
         │ localhost:23152                      └────────┬─────────────────────────────┘
 ┌───────┴───────────────────┐                           │
 │  Browser extension        │                  ┌────────┴──────────┬──────────────────┐
 │  (Chrome / Brave)         │                  │ D1  wfc-master    │ R2  wfc-blobs    │
 └───────────────────────────┘                  │ relational master │ files + archives │
                                                ├───────────────────┴──────────────────┤
 ┌───────────────────────────┐                  │ KV  config cache · session kill-marks│
 │  Phone (iOS / Android)    │  ──https/wss──▶  ├──────────────────────────────────────┤
 │  a paired device          │                  │ Durable Objects                      │
 └───────────────────────────┘                  │  ModelGate · SearchGate · UserBridge │
                                                └──────────────────┬───────────────────┘
```

على اليسار جهاز الموظف: تطبيق سطح المكتب بدماغه ذي الخمس عشرة منطقة وقدراته وأدواته، ومجلد `~/.wfc`
كذاكرة مؤقتة، وإضافة المتصفح المتصلة به على `localhost:23152` وحدها. وعلى اليمين حافة Cloudflare:
عامل واحد بأبوابه الستة، وخلفه D1 للسجل العلائقي، وR2 للملفات والأرشيف، وKV للإعدادات المؤقتة وعلامات
إبطال الجلسات، وثلاثة كائنات Durable. والهاتف يتحدث إلى الحافة مباشرة. ومفاتيح المنشأة وحدها هي ما
يخرج من الحافة إلى مضيف النماذج وخطة البحث.

## أين يعمل الوكيل

على الجهاز. دائمًا. يحمل تطبيق سطح المكتب كامل بيئة التشغيل: خمس عشرة منطقة دماغية
(`thalamus`، `ras`، `prefrontal`، `cortex`، `hippocampus`، `cerebellum`، `wernicke`، `broca`،
`amygdala`، `motor`، `basalganglia`، `hypothalamus`، `brainstem`، `corpus`، `insula`)، ومجلدات
القدرات، ومساحة العمل، ومنفّذ الأدوات، وبوابة الأمان.

يترتب على ذلك ثلاث نتائج، وهي سبب هذا التصميم:

1. **استدعاءات الأدوات لا تغادر الجهاز.** قراءة ملف، تنفيذ أمر، الضغط على صفحة في متصفح الموظف —
   لا دخل للشبكة. لا صندوق رملي يُجهَّز، ولا مستودع يُرفَع، ولا أسطول معالجات رسومية يُستأجَر.
2. **الدور يحتاج سطح مكتب يعمل.** يستطيع الهاتف قراءة كل شيء في أي وقت، لكنه لا يستطيع تشغيل دور
   وسطح المكتب نائم. ويقول ذلك صراحةً بدل أن ينتظر في صمت.
3. **بند البنية التحتية للمنشأة هو تمرير وسجل تدقيق**، لا حوسبة. لهذا فإن زيادة عمل الوكلاء تزيد
   الرموز، لا الخوادم.

## ما الغرض من الواجهة البرمجية

كل ما يجب أن يكون صحيحًا على مستوى المنشأة كلها لا على مستوى جهاز واحد:

| الشأن | من يتولاه |
| --- | --- |
| من يسجّل الدخول، على أي جهاز، ولكم من الوقت | `/auth`، `/v1/me`، علامات الإبطال في KV — [المصادقة والجلسات](/ar/api/auth) |
| أي النماذج يحق للشخص استدعاؤها، وبكم رمزًا | مسار النماذج + `ModelGate` — [المساران](/ar/api/lanes) |
| هل يُسمح ببحث في الويب، وبأي معدل | مسار البحث + `SearchGate` |
| سجل المحادثات والملفات والإعدادات | [المزامنة](/ar/sync/overview) — D1 + R2 |
| أي القدرات موجودة على كل سطح مكتب | [سجل القدرات](/ar/sync/capabilities) |
| ماذا حدث، ومن فعله | [الاستخدام والتدقيق](/ar/governance/audit) |

## كائنات Durable الثلاثة

توفّر كائنات Durable ما لا توفّره العوامل وحدها: مكانًا دائمًا أحادي الخيط للتنسيق. والثلاثة
مستخدمة لذلك تحديدًا.

## التخزين، وما في كل مخزن

- **D1 (`wfc-master`)** — السجل العلائقي: `users`، `devices`، `device_sessions`، `org`،
  `model_policies`، `conversations`، `conversation_records`، `files`، `capabilities`، `pairings`،
  `settings`، `password_resets`، `usage`، `usage_daily`، `audit_log`. يبقيه الأرشيف الليلي داخل
  نافذة ساخنة محدودة.
- **R2 (`wfc-blobs`)** — كتل الملفات المعنونة بالمحتوى، وحزم القدرات
  (`capabilities/org/<slug>/v<n>.zip`)، وأرشيفات المحادثات المضغوطة، وتصدير الاستخدام المتقاعد.
- **KV** — `AUTH_KV` لعلامات إبطال الجلسات، و`CONFIG_KV` لتخزين إعدادات المنشأة وسياسة كل مستخدم
  مؤقتًا حتى لا يقرأ المسار الساخن من D1. كلاهما ذاكرة مؤقتة: الإخفاق فيها يعني قراءة D1 ببساطة.

## ما لا يوجد على الحافة أبدًا

**محتوى** الطلبات والردود لا يُسجَّل ولا يُخزَّن في الموجّه. سجل الاستخدام يحفظ البيانات الوصفية —
من، ومتى، وأي نموذج، وكم رمزًا، وكم استغرق، وكم كلّف، وما القرار — ولا شيء غيرها. ومسار البحث
يسجّل أن بحثًا جرى، لا نص الاستعلام. ورمز قفل الجهاز المكوّن من أربعة أرقام لا يغادر الجهاز.
