الحصص تقرّر ما **تنفقه** المنشأة. وهذه الثلاثة تقرّر ما **يفعله** الوكيل، ومن يصل إلى أي أداة، وكيف
تُجمَّع الفاتورة.

## طبقة الإعدادات — المطالبة بإعداد

إعدادات كل موظف صفٌّ واحد مُزامَن. والطبقة تتيح للمنشأة المطالبة بأي مسار فيه: المسار المُطالَب به هو
قيمة المنشأة على كل جهاز، وما عداه يبقى للموظف.

```json
PUT /admin/org/config
{
  "overlay": {
    "model.default": "deepseek-ai/DeepSeek-V4.1-Flash",
    "browserExtension.port": 23152
  }
}
```

مسارات نقطية فقط، حتى **٢٠٠ مسار** و**٦٤ كيلوبايت**. و`{"overlay": {}}` يعيد كل مسار.

وهي مفروضة عند **الحدّين**، وهذا ما يجعلها ضابطًا لا اقتراحًا:

- عند كل **قراءة**، تُطبَّق قيمة المنشأة فوق الصف — فيرى العميل إعداد المنشأة.
- عند كل **كتابة**، تُطبَّق الطبقة ثانيةً — فالعميل الذي يتجاهل القفل (بناء قديم، أو طلب مصنوع يدويًا،
  أو ملف إعدادات حُرِّر على القرص) لا يستطيع تخزين شيء آخر.

ولا توجد **قائمة "مفاتيح مقفلة" منفصلة** عن قصد. القفل والقيمة التي يفرضها حقيقتان يجب إبقاؤهما
متّسقتين، ويوم تختلفان هو اليوم الذي يظن فيه مشرف أن إعدادًا مفروض وهو ليس كذلك. فالمسارات الموجودة
في الطبقة **هي** المفاتيح المقفلة.

يعرض عميل الموظف الإعداد المُطالَب به على أنه مُدار من المنشأة بدل التظاهر بأنه قابل للتحرير. وتهبط
التعديلات خلال نافذة ذاكرة الحافة — دقيقة تقريبًا — لأن الكتابة تُسقط النسخة المخزّنة. وتُدقَّق باسم
`org.config_overlay`، **بالمسار لا بالقيمة**: فقد تحمل الطبقة عنوانًا أو معرّفًا، وسجل التدقيق يقرؤه
عدد أكبر ممن يقرأ الإعدادات.

## منح القدرات — تضييق أداة

القدرة في السجل تبدأ مفتوحة للمنشأة كلها. والمنح يضيّقها.

```json
PUT /admin/capabilities/finance-reports/grants
{
  "grants": [
    { "kind": "team", "subject": "finance" },
    { "kind": "role", "subject": "admin" },
    { "kind": "user", "subject": "usr_..." }
  ]
}
```

| المنح | من يحصل عليها |
| --- | --- |
| *(لا شيء)* | الجميع — الافتراضي، ومن حيث تبدأ كل قدرة |
| واحد أو أكثر | من يطابقهم الدور أو الفريق أو معرّف المستخدم فقط |

تُطابَق المنح في **الموضعين** المهمّين: بيان القدرات الذي يزامنه الجهاز، وتنزيل الحزمة نفسه. فالقدرة
التي لا يراها أحدهم هي أيضًا قدرة لا يستطيع جلبها بتخمين معرّفها.

و`GET /admin/capabilities/:slug/grants` يقرؤها ويقول `open_to_org` صراحةً. وتُدقَّق باسم
`capability.grants`.

<Note>
تضييق قدرة يزيلها من الأجهزة التي لم تعد تطابقها، في جولة مزامنتها التالية — إذ يكفّ البيان عن
تسميتها. وتوسيعها يثبّتها بالطريقة نفسها. ولا يحتاج أيٌّ منهما تحديث عميل.
</Note>

## الفرق

الفريق حقل واحد على الشخص (`PATCH /admin/users/:id`)، ويشتري ثلاثة أشياء:

- **`GET /admin/teams`** — الكشف مجمَّعًا مستوى أعلى: الأشخاص، والنشطون، والرموز، والتكلفة،
  والطلبات، وعمليات البحث لكل فريق، خلال نافذة تختارها. وهو السؤال الأول لأي نشر بخمسمئة شخص.
- **موضوعًا للمنح** — `{"kind": "team", "subject": "finance"}` أعلاه.
- **عمودًا في الكشف**، فيصير "من في التسويق وكم ينفقون" قراءةً واحدة.

ومن لا فريق له يُجمَّع تحت الفريق الفارغ لا يُسقَط، لأن إجماليًا يُغفل غير المسنَدين بصمت أسوأ من
إجمالي يسمّيهم.

## ماذا يرى المشرف عن كل شخص

`GET /admin/users/:id/overview` هو عرض الدعم لموظف واحد في استدعاء واحد: الملف الشخصي، والدور،
والحالة، والفريق، والأجهزة، والسياسة والخطة السارية بسقوفهما، والاستخدام، ونشاطه الأخير. وحوله:

| نقطة النهاية | ماذا تجيب |
| --- | --- |
| `GET /admin/roster` | الجميع، بإنفاقهم ومكانتهم |
| `GET /admin/users/:id/audit` | ما فُعل **به** وما فعله **هو** |
| `GET /admin/users/:id/conversations` | فهرس محادثاته |
| `GET /admin/conversations/:id/records` | نص واحد، بدمج الأرشيف والصفوف الحية |
| `GET /admin/conversations/:id/files/:sha` | مرفق، أو جسم رسالة تجاوزت الحجم |

الثلاثة الأخيرة هي الحسّاسة. وهي من رتبة المشرف — **لا يصلها الدعم** — ولا يفتح مشرفٌ محادثاتِ مالك،
وكل قراءة تكتب صف تدقيق `conversation.view`. انظر [الاستخدام والتدقيق](/ar/governance/audit).

## أين يهبط كل ضابط

| الضابط | يهبط على الجهاز | يُفرض عند |
| --- | --- | --- |
| قائمة النماذج والسقوف | خلال نافذة ذاكرة الحافة (~دقيقة) | مسار النموذج، قبل القبول |
| طبقة الإعدادات | خلال نافذة الحافة، أو سحب الإعدادات التالي (~دقيقتان) | كل قراءة إعدادات **وكل** كتابة |
| منح القدرات | جولة المزامنة التالية (جاهزية الجلسة، أو بعد استيراد، أو كل ٣٠ دقيقة) | البيان **وتنزيل** الحزمة |
| الفريق | فورًا، للتقارير | التقارير ومطابقة المنح |
