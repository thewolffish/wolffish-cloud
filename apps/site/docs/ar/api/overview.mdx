`wfc-api` عامل Cloudflare واحد على **`api.wolffi.sh`**. كل ما يفعله سطح المكتب والهاتف يمرّ عبره،
وكل طلب يمرّ بسلسلة الوسائط نفسها:

```text
تحقّق من الرمز ← حدّد المستخدم ← حدّد الدور ← بوابة السياسة/الحصة ← المعالِج
```

لا بيئة ثانية بحكم التصميم: النشر **هو** النظام، و`wrangler dev` أمام مضيفات وهمية هو حلقة التطوير.

اعرف ما هو منشور بـ `GET /health`، الذي يعيد اسم الخدمة والإصدار المنشور.

## الأعراف

- **المصادقة** — رمز وصول في `Authorization: Bearer <jwt>`. الاستثناء الوحيد هو مقبس الجسر، الذي
  يقبل أيضًا `?access_token=` لأن مقبسًا بنمط المتصفح لا يستطيع ضبط ترويسة.
- **الأخطاء** — JSON بالشكل `{"error": "<code>"}` مع حالة HTTP. تعتمد العملاء على **الرمز** لا على
  النص: `email_not_found`، `wrong_password`، `rate_limited`، `account_disabled`،
  `temp_password_expired`، `session_revoked`، `forbidden`، `not_found`، `quota_exceeded`.
- **عدم التكرار** — كل عنصر مزامنة يحمل معرّفًا من العميل، فإعادة الإرسال بلا أثر، والاستجابة تسمّي
  كل عنصر رفضته.

## عام

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `GET` | `/` | صفحة الهبوط |
| `GET` | `/health` | `{ok, service, version, time}` |

## المصادقة والاقتران

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `POST` | `/auth/login` | تسجيل الدخول بكلمة مرور؛ يصدر رمز وصول ورمز تحديث |
| `POST` | `/auth/password` | تغيير إلزامي عند أول دخول، وتغيير اختياري |
| `POST` | `/auth/refresh` | تدوير رمز التحديث وإصدار رمز وصول جديد |
| `POST` | `/auth/reset/request` | إرسال رمز استعادة بالبريد |
| `POST` | `/auth/reset/confirm` | استخدام الرمز |
| `POST` | `/auth/pair/claim` | يطالب الهاتف بعرض اقتران فيتسلّم جلسة جهاز |

## واجهة الجلسة (`/v1`)

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `GET` | `/v1/me` | الهوية والدور والحالة — أول استدعاء لسطح المكتب بعد الدخول |
| `GET` | `/v1/models` | كتالوج النماذج من الخادم: ما يعرضه مُنتقي هذا المستخدم بالضبط |
| `PATCH` | `/v1/profile` | الاسم والهاتف (البريد والدور والحالة للمسؤول) |
| `PUT`&nbsp;·&nbsp;`GET`&nbsp;·&nbsp;`DELETE` | `/v1/profile/avatar` | الصورة الشخصية |
| `POST` | `/v1/device/pin` | إبلاغ حالة القفل المحلي وإقرار طلب مسحه |
| `POST` | `/v1/logout` | إبطال هذه الجلسة |
| `GET` | `/v1/devices` | أجهزة المتصل نفسه |
| `DELETE` | `/v1/devices/:id` | فك اقتران جهاز (يرفض جهاز المتصل نفسه) |
| `POST` | `/v1/pair/offer` | فتح عرض اقتران (رمز + حمولة QR) |
| `GET`&nbsp;·&nbsp;`DELETE` | `/v1/pair/offer/:id` | استعلام أو سحب العرض |
| `GET` | `/v1/bridge/ws` | ترقية WebSocket إلى جسر هذا المستخدم |
| `GET` | `/v1/bridge/status` | الحضور: هل سطح مكتبي يعمل الآن؟ |

## المزامنة (`/v1`)

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`PUT` | `/v1/config` | صف الإعدادات الوحيد، آخر كتابة تفوز |
| `POST` | `/v1/sync/batch` | تفريغ صندوق الصادر: محادثات وسجلات، بلا تكرار |
| `GET` | `/v1/sync/bootstrap` | استرجاع باستدعاء واحد: الإعدادات + الفهرس + بيان الملفات |
| `POST` | `/v1/sync/wipe` | محو سجل هذا المستخدم |
| `GET` | `/v1/conversations` | الفهرس — `after` للاسترجاع أو `since` للّحاق |
| `GET` | `/v1/conversations/:id/records` | صفحة من سجلات محادثة |
| `DELETE` | `/v1/conversations/:id` | وضع شاهدة حذف على محادثة |
| `POST` | `/v1/files/upload` | رفع معنون بالمحتوى (إزالة تكرار بـ sha256) |
| `GET` | `/v1/files/manifest` | بيان الملفات |
| `POST` | `/v1/files/delete` | شواهد حذف للملفات |
| `GET`&nbsp;·&nbsp;`HEAD` | `/v1/files/path?name=` | أحدث كتلة حية على مسار في مساحة العمل |
| `GET` | `/v1/files/:sha256` | جلب كتلة |
| `GET` | `/v1/usage` | سجل الاستخدام الخام لهذا المستخدم |
| `GET` | `/v1/usage/days` | الاستخدام مطويًا حسب اليوم |
| `GET` | `/v1/leaderboard` | ترتيب المنشأة — الرموز والمحادثات والمهام الوكيلة لكل شخص |

`/v1/leaderboard` هي القراءة الوحيدة على مستوى المنشأة المتاحة لكل مستخدم مسجَّل لا للمسؤولين فقط:
فهي المنشأة تنظر إلى نفسها. ولا تحمل مالًا عن قصد — فالتكلفة شأن مالي للمنشأة ويبقى خلف
`/admin/usage`. وتُحسب اللوحة كلها تجميعًا واحدًا وتُخزَّن مؤقتًا، فالتصفّح والبحث والترتيب كلها تقرأ
لقطة واحدة؛ والمرتبة هي المرتبة في **كل** المنشأة حتى حين تُرشَّح القائمة إلى اسم واحد.

## الإدارة (`/admin`)

القراءة متاحة لـ `owner` و`admin` و`support`؛ والتعديل لـ `owner` و`admin` فقط، ولا يمسّ المالكَ
إلا مالك. وكل تعديل يكتب صف تدقيق.

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`POST` | `/admin/users` | القائمة، والدعوة |
| `GET`&nbsp;·&nbsp;`PATCH` | `/admin/users/:id` | القراءة والتعديل (الدور، الحالة، الملف) |
| `POST` | `/admin/users/:id/reset-password` | إصدار كلمة مرور مؤقتة |
| `POST` | `/admin/users/:id/clear-pin` | طلب مسح القفل المحلي على جهاز |
| `POST` | `/admin/users/:id/revoke-sessions` | إبطال كل جلسات المستخدم |
| `PUT` | `/admin/users/:id/policy` | قائمة النماذج المسموحة والسقوف |
| `GET`&nbsp;·&nbsp;`PUT` | `/admin/users/:id/config` | قراءة أو إصلاح إعدادات مستخدم |
| `GET`&nbsp;·&nbsp;`PATCH` | `/admin/org` | افتراضات المنشأة: النموذج، القائمة، السقوف، مفتاح البحث |
| `GET`&nbsp;·&nbsp;`PUT`&nbsp;·&nbsp;`DELETE` | `/admin/capabilities[/:slug]` | سجل القدرات |
| `GET` | `/admin/usage` | إجماليات كل مستخدم من التجميع اليومي |
| `GET` | `/admin/gates` | حالة البوابات الحية |
| `POST` | `/admin/maintenance/run` | تشغيل المهام الليلية الآن |
| `GET` | `/admin/audit` | سجل التدقيق |

<Note>
**واجهة** الإدارة تعيش داخل تطبيق سطح المكتب الخاص بالمسؤول. وكل نقطة نهاية تعيد التحقق من الدور
على الخادم، فالواجهة عرضٌ فقط — وإخفاء زر ليس ضابطًا.
</Note>
