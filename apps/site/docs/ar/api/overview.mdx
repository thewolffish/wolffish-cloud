الواجهة البرمجية الرئيسة عامل Cloudflare واحد في حساب المنشأة نفسها. وكل ما يفعله سطح المكتب
والطرفية والهاتف يمر عبره، وكل طلب يجري في سلسلة الوسائط نفسها:

```text
تحقّق من الرمز ← حدّد المستخدم ← حدّد الدور ← بوابة السياسة/الحصة ← المعالج
```

ولا توجد بيئة ثانية عن قصد: النشر **هو** النظام، و`wrangler dev` أمام مضيفات وهمية هو حلقة التطوير.

تحقّق مما هو حيّ بـ `GET /health`، فيجيب باسم الخدمة والنسخة المنشورة.

## الأعراف

- **المصادقة** — رمز وصول حامل على `Authorization: Bearer <jwt>`. واستثناءان: مقبس الجسر يقبل
  أيضًا `?access_token=` لأن مقبسًا بأسلوب المتصفح لا يستطيع ضبط ترويسة، ومسار النشر له مفتاحه.
- **الأخطاء** — JSON بالشكل `{"error": "<code>"}` مع حالة HTTP. والعملاء يربطون على *الرمز* لا على
  الرسالة: `email_not_found` و`wrong_password` و`rate_limited` و`account_disabled`
  و`temp_password_expired` و`already_active` و`invalid_code` و`code_expired` و`session_revoked`
  و`forbidden` و`not_found` و`quota_exceeded` و`payload_too_large`.
- **عدم التكرار** — كل عنصر مزامنة يحمل معرّفًا يولّده العميل، فالإعادة لا تفعل شيئًا، والرد يسمّي كل
  عنصر رفضه.

## العام

| الطريقة | المسار | ماذا تفعل |
| --- | --- | --- |
| `GET` | `/` | صفحة الهبوط |
| `GET` | `/health` | `{ok, service, version, time}` |

| `POST` | `/auth/reset/confirm` | استهلاك الرمز |

## المزامنة (`/v1`)

| الطريقة | المسار | ماذا تفعل |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`PUT` | `/v1/config` | صف الإعدادات الواحد، آخر كتابة تفوز، مع طبقة المنشأة مُطبَّقة |
| `POST` | `/v1/sync/batch` | تفريغ صندوق الصادر: المحادثات وسجلاتها، بلا تكرار |
| `GET` | `/v1/sync/bootstrap` | استرجاع باستدعاء واحد: الإعدادات وفهرس المحادثات وبيان الملفات |
| `POST` | `/v1/sync/wipe` | محو السجل المُزامَن لهذا المستخدم |
| `GET` | `/v1/conversations` | الفهرس — `after` (للاسترجاع) أو `since` (للّحاق) |
| `GET` | `/v1/conversations/:id/records` | صفحة من سجلات محادثة واحدة |
| `DELETE` | `/v1/conversations/:id` | وضع شاهدة حذف على محادثة |
| `POST` | `/v1/files/upload` | رفع معنون بالمحتوى (إزالة التكرار بـ sha256) |
| `GET` | `/v1/files/manifest` | بيان الملفات |
| `POST` | `/v1/files/delete` | شواهد حذف الملفات |
| `GET`&nbsp;·&nbsp;`HEAD` | `/v1/files/path?name=` | أحدث كتلة حية على مسار في مساحة العمل |
| `GET` | `/v1/files/:sha256` | جلب كتلة |
| `GET` | `/v1/usage` | سجل الاستخدام الخام لهذا المستخدم |
| `GET` | `/v1/usage/days` | الاستخدام مطويًّا بالأيام |
| `GET` | `/v1/leaderboard` | ترتيب المنشأة — الرموز والمحادثات والمهام الوكيلية لكل شخص |

`/v1/leaderboard` هي القراءة الوحيدة على مستوى المنشأة المفتوحة لكل من سجّل الدخول لا للمشرفين
وحدهم: فهي المنشأة تنظر إلى نفسها. ولا تحمل مالًا عن قصد — التكلفة شأن مالي للمنشأة ويبقى خلف
`/admin/usage`. وتُحسب اللوحة كلها تجميعةً واحدة وتُخزَّن، فالتصفّح والبحث والترتيب كلها تقرأ لقطة
واحدة؛ والترتيب هو الترتيب في **كل** المنشأة حتى حين تُرشَّح القائمة باسم واحد.

## الإدارة (`/admin`)

كل نقطة نهاية تعيد التحقق من الصلاحية على الخادم مقابل جدول قواعد واحد
(`src/lib/permissions.ts`). القراءات من رتبة `support` فما فوق، والتعديلات من `admin` فما فوق،
والقراءتان الحسّاستان لـ `admin` وحده، ولا يتصرّف تجاه مالك إلا مالك. وكل تعديل يكتب صف تدقيق.

**الأشخاص**

| الطريقة | المسار | الرتبة |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`POST` | `/admin/users` | سرد `support` · دعوة `admin` |
| `GET`&nbsp;·&nbsp;`PATCH` | `/admin/users/:id` | قراءة `support` · تعديل `admin` |
| `GET` | `/admin/roster` | الجميع، بإنفاقهم ومكانتهم — `support` |
| `GET` | `/admin/users/:id/overview` | شخص واحد في استدعاء واحد — `support` |
| `POST` | `/admin/users/:id/activation` | إعادة إرسال رمز الدعوة — `admin` |
| `GET` | `/admin/users/:id/activation-code` | قراءة رمز معلّق — `admin`، وفي النشر الذي اختار ذلك فقط |
| `POST` | `/admin/users/:id/reset-password` | سكّ كلمة مرور مؤقتة — `admin` |
| `GET` | `/admin/users/:id/reset-code` | قراءة رمز استعادة معلّق — `admin`، الاختيار نفسه |
| `POST` | `/admin/users/:id/clear-pin` | طلب مسح القفل المحلي — `admin` |
| `POST` | `/admin/users/:id/revoke-sessions` | قتل كل جلسات هذا المستخدم — `admin` |
| `GET` | `/admin/users/:id/audit` | ما فُعل به وما فعله — `support` |

**الحوكمة**

| الطريقة | المسار | الرتبة |
| --- | --- | --- |
| `PUT` | `/admin/users/:id/policy` | قائمة السماح والسقوف اليومية لشخص — `admin` |
| `PUT` | `/admin/users/:id/plan` | خطة الرموز الشهرية — `admin` |
| `GET` | `/admin/plans` | كتالوج الخطط وسقوفها — `support` |
| `GET` | `/admin/teams` | المنشأة مجمَّعة بالفرق — `support` |
| `GET`&nbsp;·&nbsp;`PATCH` | `/admin/org` | افتراضيات المنشأة: النموذج وقائمة السماح والسقوف ومفتاح البحث — الكتابة `admin` |
| `GET`&nbsp;·&nbsp;`PUT` | `/admin/org/config` | [طبقة الإعدادات](/ar/governance/org-controls) — الكتابة `admin` |

**القراءتان الحسّاستان** — لـ `admin` وحده، لا لـ `support` أبدًا، ولا لمحادثات مالك إلا لمالك، وكلٌّ منهما تكتب صف تدقيق.

| الطريقة | المسار | ماذا تعيد |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`PUT` | `/admin/users/:id/config` | قراءة إعدادات مستخدم مُزامَنة أو إصلاحها |
| `GET` | `/admin/users/:id/conversations` | فهرس محادثاته |
| `GET` | `/admin/conversations/:id/records` | نص واحد، بدمج الأرشيف والصفوف الحية |
| `GET` | `/admin/conversations/:id/files/:sha256` | مرفق، أو جسم رسالة تجاوزت الحجم |

**السجل، ومراقبة النظام**

| الطريقة | المسار | الرتبة |
| --- | --- | --- |
| `GET`&nbsp;·&nbsp;`PUT`&nbsp;·&nbsp;`DELETE` | `/admin/capabilities[/:slug]` | سجل قدرات المنشأة — الكتابة `admin` |
| `GET`&nbsp;·&nbsp;`PUT` | `/admin/capabilities/:slug/grants` | من تصل إليه القدرة — الكتابة `admin` |
| `GET` | `/admin/usage` | الإجماليات لكل مستخدم، من التجميعة اليومية — `support` |
| `GET` | `/admin/gates` | حالة البوابات الحية: عمق الطابور، والجاري لكل مضيف، وفترات التهدئة — `support` |
| `POST` | `/admin/maintenance/run` | تشغيل المهام الليلية الآن — `admin` |
| `GET` | `/admin/audit` | سجل التدقيق — `support` |

<Note>
**واجهة** الإدارة تعيش داخل عميل سطح المكتب الخاص بالمشرف. وكل نقطة نهاية تعيد فحص الدور على
الخادم، فالواجهة عرضٌ فقط — وإخفاء زر ليس ضابطًا.
</Note>

## مسار النشر (`/publish`)

باب ثانٍ صغير عن قصد، يُصادَق بمفتاح `PUBLISH_TOKEN` حاملٍ لا بشخص: أربعة مسارات، ونطاق قدرات
المنشأة وحده، فلا يحمل خط التكامل المستمر الذي ينسخ `capabilities/` إلى السجل جلسةَ مالك أبدًا.
وغياب السر يجعل المسار كله يجيب بـ 404.

| الطريقة | المسار |
| --- | --- |
| `GET` | `/publish/capabilities` |
| `PUT`&nbsp;·&nbsp;`DELETE` | `/publish/capabilities/:slug` |
| `GET` | `/publish/capabilities/:slug/package` |

وبيانه هو السجل **كما هو** — غير مُرشَّح بالمنح، بخلاف بيان العملاء — لأن الناشر يجب أن يرى كل ما هو
مسؤول عنه. وتُدقَّق كتاباته بـ `ci:publish` فاعلًا. انظر [إقامة النشر](/ar/operations/rollout).
